# 第一批可组合 GA 原型

Goal: 实现投射物、多重射击、范围爆发、持续光束、临时地表、环绕实体、周期领域、陷阱八个可学习、装备、存档的原型。

Architecture: GA 负责输入、目标验证、一次性费用/冷却和引导生命周期；数据资产负责数值、表现和组合连接；服务端运行体负责碰撞、周期、伤害和派生行为，复制 Actor/表现给客户端。复用项目完整 DamageEffectParams 通路、现有环绕火球 Actor 和地表接触系统。组合使用 OnHit/OnPeriod/OnExpire，限制深度和每次施法派生总数。取消/死亡/换图不触发到期组合。

Tech stack: UE 5.8 C++/GAS/Niagara/UMG，项目绑定 MCP + 编辑器 Python。

Spec: 用户上一轮批准的第一批八种行为原型。默认数值用于原型验证，数据资产可调；新技能默认可学习，不覆盖玩家已装备槽位。光束按住引导；环绕按键切换，装备默认关闭。

Global constraints: 保留已有未提交修改及存档；不自动提交；资产先备份再改；新反射类型全量编译重启；描述保持短小；伤害只在服务器结算。
